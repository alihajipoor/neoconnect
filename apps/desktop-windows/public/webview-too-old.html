Neoxify can't show its screen

The part of Windows that draws this app, Microsoft Edge WebView2 Runtime, is out of date on this computer (version ). Neoxify can't show its screen correctly until it is updated.

What to do

  1. Update Microsoft Edge, or download the WebView2 Runtime from Microsoft's website and install it.
  2. Close this window and open Neoxify again.

If the update doesn't work, contact Neoxify support and we'll help you.

نئوکسیفای نمی‌تواند صفحه‌اش را نشان دهد

بخشی از ویندوز که صفحهٔ این برنامه را نمایش می‌دهد، یعنی Microsoft Edge WebView2 Runtime، روی این کامپیوتر قدیمی است (نسخهٔ ). تا وقتی به‌روز نشود، نئوکسیفای نمی‌تواند صفحه‌اش را درست نشان دهد.

چه کار کنید

  1. مرورگر Microsoft Edge را به‌روز کنید، یا WebView2 Runtime را از سایت مایکروسافت دانلود و نصب کنید.
  2. این پنجره را ببندید و نئوکسیفای را دوباره باز کنید.

اگر به‌روزرسانی درست نشد، به پشتیبانی نئوکسیفای پیام بدهید تا کمکتان کنیم.
