Neoxify can't open properly on this computer

Neoxify draws its window with a part of Windows called Microsoft Edge WebView2 Runtime. On this computer it is out of date (version ), so the app can't be shown correctly.

What to do

  1. Download the WebView2 Runtime from Microsoft's website and install it.
  2. Close this window and open Neoxify again.

If that doesn't help, message Neoxify support and we'll help you.

نئوکسیفای روی این کامپیوتر درست باز نمی‌شود

نئوکسیفای پنجره‌اش را با بخشی از ویندوز به نام Microsoft Edge WebView2 Runtime نمایش می‌دهد. این بخش روی کامپیوتر شما قدیمی است (نسخهٔ ) و تا به‌روز نشود، برنامه درست نمایش داده نمی‌شود.

چه باید کرد

  1. WebView2 Runtime را از سایت مایکروسافت دانلود و نصب کنید.
  2. این پنجره را ببندید و نئوکسیفای را دوباره باز کنید.

اگر باز هم درست نشد، به پشتیبانی نئوکسیفای پیام بدهید تا کمکتان کنیم.
